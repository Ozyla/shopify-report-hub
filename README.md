# Shopify Reports UI Prototype

A responsive front-end prototype for a multi-store Shopify reporting application.

## Preview
Open `index.html` in a browser. No build tools are required.

## Included screens
- Dashboard with sales KPIs, trend chart, channel mix, top products and activity
- Report Library
- Custom Report Builder prototype with field search, column selection, filters and preview area
- Stores, Products & Inventory, Customers, Schedules and Settings placeholders

## Important
This is the first UI milestone. It uses sample figures and does not connect to Shopify or save reports yet. Backend, database, secure Shopify OAuth, real sync jobs, calculations and exports are subsequent development milestones.
